# HISOB PRO

**Пулҳои худро оқилона идора кунед.**

Платформаи воқеии коркунанда барои маблағҳои шахсӣ ва тиҷорати хурд:

- 💰 Даромад ва 💸 хароҷот: илова, таҳрир, нест, ҷустуҷӯ, филтр
- 📊 Dashboard: рақамҳои имрӯз ва моҳ, графикҳои 7 рӯз / 30 рӯз / 12 моҳ
- 🏦 Ҳамёнҳо: нақд, корт, бонк, ҳамёни электронӣ; интиқол байни онҳо
- 🤝 Қарзҳо: додашуда ва гирифташуда, пардохти қисм-қисм, муҳлатгузашта
- 🎯 **Мақсадҳои пасандоз:** «Телефон — 3000 смн то 1 март» → пешрафт ва «ҳар рӯз чанд гузоред»
- 📅 **Пардохтҳои доимӣ:** иҷора, интернет, маош… — дар рӯзи пардохт бот ёдрас мекунад, «✅ Пардохт шуд» худкор сабт мекунад
- 💱 **Қурби худкор** аз Бонки миллии Тоҷикистон (nbt.tj) ҳар рӯз (захира: қурби бозор)
- 📅 Ҳисоботҳо: рӯзона, ҳафтаина, моҳона, солона; содирот ба PDF, Excel, CSV
- 🔐 Сабти ном, воридшавӣ, иваз ва барқарор кардани парол; маълумоти ҳар корбар ҷудо ва ҳифзшуда
- 🌙 Мавзӯи торик ва равшан; забонҳо: тоҷикӣ ва русӣ; дар телефон ва компютер кор мекунад

🔒 **Платформаи шахсӣ:** танҳо ҳисоби аввалин сохта мешавад, баъд аз он сабти ном пӯшида аст. Барои кушодан: Render → `hisob-pro` → *Environment* → `REGISTRATION` = `open`.

📱 **Барнома дар телефон:** сайтро кушоед → **Танзимот → Барнома дар телефон → Насб кардан** (Android) ё дар Safari **«Мубодила» → «На экран „Домой“»** (iPhone). HISOB PRO мисли барнома бо нишонаи худ, бе сатри браузер кушода мешавад. Тугмаи калони ➕ дар поёни экран — барои зуд илова кардани даромад/хароҷот бо як даст.

🤖 **Telegram-бот:**
- ✍️ сабт бо як паём: `50 хӯрок`, `+3000 маош`; 📸 сурат бо навиштаи `50 нон` — харид бо сурат
- 21:00 — ҳисоботи рӯз, **албоми суратҳои харидҳои рӯз**, **нусхаи эҳтиётии Excel** (бе садо)
- огоҳии фаврӣ, агар хароҷот аз меъёр гузарад — бо нишон додани он, ки пул ба куҷо меравад
- 📍 **Ҷадвали рӯз:** ҳангоми даромадан ба барнома мепурсад «пулро бештар дар куҷо сарф мекунед?» — ҷой, соати даромадан ва баромадан (масалан «Иловагӣ» 16:00–18:00). Ҳар рӯз **5 дақиқа пеш аз баромадан** бот хабар медиҳад: «лутфан пардохти хароҷотро сабт кунед»; ҷавоб — танҳо рақам (`10`). Фармон: `/routine Иловагӣ 16:00-18:00`
- 09:00 — **ёдраскунии қарзҳо** (пагоҳ, имрӯз, муҳлатгузашта)

- фармонҳо: `/today`, `/month`, `/balance`, `/debts`, `/photos`, `/limit 500`, `/daily`, `/routine`, `/goal 200`, `/code`, `/stop`

📱 **Сабти ном:** соҳиб (корбари аввал) — бо email; дигарон — **танҳо бо рақами Telegram** (як рақам — як ҳисоб). Воридшавӣ: рақам ё email + парол. Барқарорсозии парол — **коди 6-рақама** ба Telegram (15 дақиқа, 5 кӯшиш); ё дар бот `/code`. Дар бот тугмаи 📱 рақамро ба ҳисоб сабт мекунад (воридшавӣ бо рақам). Соҳиб сабти номро дар **Танзимот** мепӯшад/мекушояд.

📸 **Суратҳои харид:** дар формаи хароҷот — «Сурат гирифтан ё интихоб кардан» (камера ё галерея); сурат дар телефон фишурда мешавад (~100–300 KB) ва дар база нигоҳ дошта мешавад.


**Технологияҳо:** React, TypeScript, Tailwind CSS, Recharts, Node.js, Express, PostgreSQL, Prisma.

## Сайт дар интернет
👉 **https://manuchekhrbekhbudov-dot.github.io/oshi-bunafwa-/**

Ин линк платформаро мекушояд, ки дар **https://hisob-pro.onrender.com** (Render.com) кор мекунад.

Сервери ройгони Render баъд аз 15 дақиқаи беамалӣ «хоб» меравад. Барои ҳамин сервер ҳар 10 дақиқа худашро бедор нигоҳ медорад (захира: GitHub Actions `keep-alive.yml`), то сайт фавран кушода шавад. Хомӯш кардан: Render → Environment → `KEEP_ALIVE=off`.

Ҳар тағйире, ки ба branch-и `main` push мешавад, сайтро **худкор нав мекунад**. Танзимоти Render дар файли [`render.yaml`](render.yaml) аст.

### 🗄 Базаи маълумот — Neon (ройгон ва доимӣ)
Базаи ройгони Render баъди 30 рӯз нест мешавад, барои ҳамин база ба **[Neon](https://neon.tech)** мегузарад:
1. neon.tech → *Sign up* (бо GitHub) → лоиҳаи нав `hisob-pro` (минтақа — ҳамон, ки сервери Render: Oregon ё Frankfurt).
2. *Connect* → суроғаи `postgresql://…neon.tech/neondb?sslmode=require…`-ро нусха кунед (ҳамон тавр, ки ҳаст).
3. Render → база `hisob-pro-db` → *Internal Database URL*-ро нусха кунед.
4. Render → `hisob-pro` → *Environment*: `OLD_DATABASE_URL` = суроғаи қадами 3, `DATABASE_URL` = суроғаи Neon → *Save, rebuild and deploy*.
5. Ҳангоми оғоз сервер ҳамаи маълумотро (корбарон, амалиётҳо, суратҳо, Telegram…) худкор нусха мекунад — дар Logs: `[db-copy] маълумот кӯчонида шуд`.

Ин суроғаҳо паролро дар бар мегиранд — онҳоро ба касе нафиристед.

## Ба кор андохтан дар компютер (VS Code)
Ба шумо Node.js 20+ ва PostgreSQL (ё Docker) лозим аст. Дар папкаи `hisob-pro`:

```bash
npm install
docker compose up -d
npm run setup
npm run dev
```

Баъд http://localhost:5173 -ро кушоед. Воридшавии демо: **demo@hisob.pro** / **demo12345**.

Дастури пурра, структураи проект ва API дар [`hisob-pro/README.md`](hisob-pro/README.md).
